## Быстрый старт

```bash
# 1. Клонировать / скопировать папку
# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить (обычный режим)
python main.py

# 4. Запустить (демо-режим для жюри — клавиши управления)
python main.py --demo

# 5. Если камера не найдена
python main.py --cam 1 --demo
```

---

## Клавиши управления

| Клавиша | Действие |
|---------|----------|
| `H`     | Симулировать каску (демо-режим) |
| `V`     | Симулировать жилет (демо-режим) |
| `SPACE` | Перейти на следующий шаг (демо) |
| `R`     | Рестарт сначала |
| `Q` / `ESC` | Выйти |

## Архитектура

```
main.py (один файл, ~450 строк, 3 слоя)
│
├── CV-СЛОЙ
│   ├── YOLOv8n → детекция человека и оборудования (COCO)
│   ├── HSV-анализ → каска (жёлтый/оранжевый/белый)
│   │                жилет (жёлтый/оранжевый/салатовый)
│   └── MediaPipe Hands → поднятая рука у кнопки
│
├── FSM-СЛОЙ (5 состояний)
│   ├── PPE_CHECK      — проверка каски и жилета
│   ├── ACCESS_GRANTED — допуск выдан (+40 очков)
│   ├── STEP1_WORKSTATION — найти рабочее место (+20)
│   ├── STEP2_POWER    — поднять руку к кнопке (+30)
│   └── COMPLETE       — квест пройден! (+10)
│
└── UI-СЛОЙ (OpenCV overlay)
    ├── draw_yolo_boxes()     — bounding boxes объектов
    ├── draw_ppe_panel()      — прогресс-бары СИЗ
    ├── draw_ar_guide()       — пульсирующая AR-стрелка
    ├── draw_access_banner()  — анимация допуска
    ├── draw_complete_screen()— финальный экран
    └── draw_status_bar()     — Safety Score + подсказка
```

## Веса YOLOv8n

Скачиваются **автоматически** при первом запуске (~6MB):
```
https://github.com/ultralytics/assets/releases/download/v8.2.0/yolov8n.pt
```

Для оффлайн-демо: скачать вручную и положить рядом с `main.py`.

## Почему это оригинально (ответ жюри)

| Критерий | Наш подход |
|----------|-----------|
| **Не просто инструкция** | Геймификация: Safety Score 0–100, прогресс-бары, финальный экран достижения |
| **Оригинальный сценарий** | FSM-квест: СИЗ → допуск → рабочее место → кнопка → сертификат |
| **Работающее CV-ядро** | YOLOv8n + HSV + MediaPipe — три метода детекции |
| **Польза для молодёжи** | Мгновенная обратная связь, AR-стрелки, нет бумаг, язык геймера |
| **Снижение стресса** | "Допуск выдан" — момент эмоциональной поддержки через экран |
